GrupTakip WhatsApp Worker

Bu servis surekli calisan Node.js 20+ makinede calisir. Ilk acilista terminalde QR uretir. QR, WhatsApp > Bagli cihazlar uzerinden okutulduktan sonra grup katilimci ekleme olaylarini dinler.

Kurulum: worker klasorunde npm install, ardindan ortam degiskenlerini ayarlayip npm start.

auth klasoru WhatsApp oturum bilgisidir. GitHub'a yuklemeyin ve kimseyle paylasmayin.

Not: Worker resmi WhatsApp Cloud API yerine WhatsApp Web protokolunu kullanan ucuncu taraf Baileys kutuphanesine dayanir. WhatsApp degisiklikleri nedeniyle bakim gerektirebilir. Yalnizca yonetme veya takip etme yetkiniz bulunan gruplarda kullanin.
