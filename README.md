# GrupTakip

WhatsApp gruplarına yeni katılan üyeleri takip etmek için yönetim paneli.

## Durum
İlk sürüm: yönetim paneli iskeleti hazır. Sonraki adım QR oturum servisi, grup seçimi ve katılımcı olaylarının kalıcı veritabanına kaydı.

> WhatsApp oturum servisi Vercel dışında sürekli çalışan bir Node.js süreç olarak tasarlanacaktır. Yalnızca yönettiğiniz veya takip etme yetkiniz bulunan gruplarda kullanın.
